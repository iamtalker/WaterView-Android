# 물뷰 Android

WaterView의 안드로이드 올인원 뷰어 개발 폴더입니다.

목표 지원 형식: 이미지, 압축 만화, PDF, TXT/Markdown, 동영상, MP3.

현재 단계는 Android 파일 선택기와 이미지·TXT/Markdown·PDF 첫 페이지·ZIP/CBZ 이미지 페이지 넘김까지 연결한 초기 뷰어입니다. 동영상·음악은 우선 외부 앱으로 열 수 있고, 이후 자체 플레이어를 연결합니다.

첫 배포부터 업데이트 확인 기능을 포함합니다. 앱의 `업데이트 확인` 버튼이 GitHub 릴리스 API를 확인하며, 배포 저장소는 `iamtalker/WaterView-Android`로 고정해 두었습니다.
