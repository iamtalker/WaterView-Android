# 물뷰 Android

데스크톱 물뷰의 사용감을 안드로이드로 확장하는 올인원 파일 뷰어입니다.

## 기반

이 앱은 [Gander](https://github.com/mokshablr/gander)를 Android 파일 처리·문서·미디어 뷰어 기반으로 포크했습니다. Gander의 MIT 라이선스와 포함된 라이브러리별 고지를 유지하며, 물뷰의 이름·색상·아이콘·읽기 경험을 별도로 적용합니다.

## 지원 목표

- 이미지: JPG, PNG, GIF, WEBP, BMP, TIFF, SVG 등
- 압축 만화: ZIP, CBZ, CBR, RAR, 7Z 계열
- 문서·텍스트: PDF, Markdown, TXT, DOCX, XLSX, PPTX 등
- 동영상·음악: MP4, MKV, AVI, MOV, MP3 등

## 현재 구현

Gander의 Android 파일·문서 처리 기반 위에 물뷰의 한국어 UI와 읽기 경험을 적용했습니다. 일반 뷰어 기능에 더해 다음 항목을 구현했습니다.

- **만화:** 일본식 오른쪽에서 왼쪽 읽기, 한 화면 한 페이지 보기, 넓은 그림 반쪽 분할 보기
- **ZIP 만화:** 그림 위주 ZIP을 누르면 압축 목록 대신 만화 뷰어로 바로 열기
- **TXT·Markdown:** 스크롤 읽기와 좌우 탭 페이지 넘김 지원. .txt는 전용 화면에서 세로 스크롤로 읽고, Markdown 등 다른 텍스트 형식은 설정의 "페이지 넘김 방식 (Markdown 등)"에서 세로 스크롤/가로 페이지 넘김을 고릅니다. 글자 크기는 설정에서 조절합니다
- **PDF:** 세로 스크롤 또는 한 페이지씩 가로 넘김 선택, 넓은 페이지 반쪽 분할 옵션. 뷰어 메뉴에서 페이지 확대율을 조절합니다
- **PDF 조작:** 페이지 위치 막대, 가로 넘김 모드의 이전·다음 버튼, 읽기 도구 모음 표시·숨김
- **설정 반영:** PDF 보기 방식을 바꾸면 문서를 닫지 않고 현재 화면에 적용; 세로 스크롤에서는 하단 페이지 넘김 버튼 숨김
- **전자책·문서:** EPUB 장별 읽기와 DOCX·XLSX·PPTX 등 문서 뷰어
- **안정성:** 만화 페이지 전환 깜빡임 완화와 PDF 페이지 미리 준비
- **텍스트 뷰어:** 읽던 위치 이어보기, 북마크(추가·목록·이동·삭제), 강제 줄바꿈 정리(문단으로 잇기), 파일 안 찾기
- **최근 파일:** 파일 열기로 연 파일을 최근 목록에 표시하고 다시 열 수 있습니다. 목록의 줄을 길게 누르면 목록에서 뺄 수 있습니다
- **폴더 안 이동:** 폴더에서 연 파일은 메뉴에서 이전·다음 파일로 바로 넘어갈 수 있습니다. zip 만화는 zip 안의 마지막 쪽에서 다음을 누르면 같은 폴더의 다음 zip으로 넘어갑니다
- **읽어주기:** 텍스트 파일과 글자가 있는 PDF를 기기의 기본 음성으로 읽습니다. 메뉴의 "읽어주기"를 누르면 시작하고 "읽기 멈추기"로 멈춥니다. 음성 파일을 따로 넣지 않으며 인터넷을 쓰지 않습니다. PDF는 WebView 125 이상인 기기에서만 나타나고, 스캔한 PDF처럼 글자가 없으면 "읽을 글자가 없습니다"라고 알려 줍니다
- **만화 북마크:** 폴더나 zip의 만화에서 쪽을 북마크에 넣고 목록에서 그 쪽으로 이동할 수 있습니다. 북마크는 파일 이름과 쪽 번호만 저장합니다
- **이어보기:** zip 만화는 나갔다가 다시 열면 읽던 쪽에서 이어집니다. 텍스트 파일과 PDF도 읽던 위치에서 이어집니다
- **텍스트 화면:** 텍스트 파일은 전용 화면에서 엽니다. 파일을 복사해 줄 위치만 색인하고 보이는 줄만 읽어서, 수 MB 이상의 파일도 바로 열립니다. 위치 기억, 북마크, 문서에서 찾기, 읽어주기를 지원합니다. 페이지 넘김은 스냅 없이 부드럽게 스크롤합니다
- **텍스트 문서에서 찾기(0.2.53):** 찾는 말을 넣으면 문서 전체를 세서 "현재 / 전체"(예: 3 / 17)를 하단 줄에 보여 줍니다. 이전·다음 버튼으로 앞뒤로 옮기고, 닫기를 누르면 강조와 줄이 사라집니다. 10,000개를 넘으면 "10000개 이상"으로 씁니다.
- **북마크 삭제(0.2.53):** 북마크 목록의 각 항목 옆에 삭제 버튼이 있습니다. 누르면 그 북마크만 지우고 목록은 열린 채로 남습니다. 텍스트 화면과 뷰어(PDF·Markdown·zip)가 같은 목록을 씁니다.
- **텍스트 쪽 표시:** 하단 오른쪽 "현재 쪽 / 전체 쪽"을 누르면 쪽 번호를 입력해 그 쪽으로 갑니다. 쪽 수는 줄 높이의 평균으로 추정한 값이라 실제 쪽 경계와 조금 다를 수 있습니다 끝까지 내려가면 마지막 화면이 마지막 쪽(N / N)으로 표시됩니다.
- **텍스트 탭 넘기기:** 화면 위쪽 3분의 1을 누르면 위로, 아래쪽 3분의 1을 누르면 아래로 한 화면씩 넘어갑니다. 가운데를 누르면 제목과 조작줄, 시스템 바가 사라지고 다시 누르면 돌아옵니다
- **텍스트 하단:** 진행 막대, ‹ › 버튼(한 화면씩), 설정 버튼이 있습니다. 설정 버튼은 읽기 설정 창을 엽니다. 글자 크기는 그 창의 TXT 보기에서 바꾸며, 텍스트 화면에 바로 반영됩니다
- **다음 권 넘기기(JPG 폴더 만화):** 그림이 든 폴더로 읽는 만화는 마지막 쪽에서 다음을 누르면 같은 위치의 다음 폴더(1권 폴더 → 2권 폴더 → 10권 폴더, 숫자 순)의 첫 그림을 엽니다. 처음 한 번은 권 폴더들이 든 상위 폴더를 허용해야 하고, 허용한 뒤에는 묻지 않습니다. 마지막 권의 마지막 쪽에서는 그 자리에 머뭅니다. 예전에는 같은 폴더의 다음 그림으로 가서 같은 권의 앞쪽으로 돌아간 것처럼 보였습니다. 에뮬레이터에서 3권(각 3장)으로 확인했고 갤럭시 A23에서도 잘 작동한다고 확인받았습니다
- **다음 파일 넘기기:** 폴더에서 연 PDF, 텍스트, zip 만화는 마지막 쪽에서 다음을 누르면 같은 폴더의 다음 파일을 이름순(1권, 2권, 10권)으로 엽니다. 다른 앱에서 열 때는 파일이 있는 폴더를 한 번 허용해야 합니다. 다음 파일이 없으면 그 자리에 머뭅니다
- **진단 기록:** 설정 맨 아래의 "진단 기록"에서 텍스트 쪽 나누기 과정과 PDF 쪽 그리기 시간을 보고, 복사하거나 지울 수 있습니다. 기록은 이 기기에만 있습니다. PDF는 열 때 `pdf: opened viewer=pdf.js horizontal=true webview=…`로 어느 뷰어(pdf.js/simple)로, 가로 모드인지, WebView 버전이 무엇인지 남고, 쪽을 넘기고 그림이 나올 때까지 0.3초 넘게 걸리거나 그리기가 0.2초 넘게 걸린 쪽만 `pdf: page N turn-to-picture X ms (finding page, waited, load, draw)`로 남습니다. finding page는 대상 쪽을 찾는 시간, waited는 그리기 시작을 기다린 시간, load는 pdf.js가 쪽을 읽은 시간, draw는 그리는 시간입니다. 간단히 보기에서도 그림이 오는 시간을 기록합니다
- **읽어주기 음성 언어:** 글에 한글이 있으면 한국어 음성으로 읽습니다. 한국어 음성이 기기에 없으면 기기의 텍스트 음성 변환 설정에서 설치해야 합니다
- **업데이트 알림:** 하루 한 번 새 버전을 확인하고, 새 버전이 있으면 알림을 띄웁니다. 앱을 열 때와 앱을 닫은 동안(WorkManager가 하루 한 번) 모두 확인합니다. 알림을 누르면 업데이트를 확인하는 창이 열립니다
- **밖에서 연 사진 넘기기:** 파일 관리자 등 다른 앱에서 연 사진은 그 사진의 폴더를 선택창에 미리 띄웁니다. "이 폴더 사용"과 허용을 한 번 누르면 같은 폴더의 사진을 옆으로 넘겨 볼 수 있습니다. 허용한 폴더는 기억하며, 목록에는 나열하지 않습니다
- **가로 위치 막대:** 텍스트 뷰어는 하단 막대로 파일 안의 위치(퍼센트)를 보고 끌어서 옮길 수 있습니다. PDF와 만화는 쪽 번호 막대로 같은 방식으로 이동합니다
- **가운데 탭 메뉴:** 텍스트, PDF, 만화 페이지의 가운데를 가볍게 누르면 툴바와 하단 막대가 나타나거나 사라집니다
- **전체 화면 유지:** 전체 화면에서 문서를 스크롤해 맨 위에 도달해도 툴바만 따로 나타나지 않습니다
- **PDF 북마크:** PDF 쪽을 북마크에 넣고 목록에서 바로 이동할 수 있습니다
- **만화 zip 제목:** 만화 상단에 파일 번호 대신 zip 파일 이름이 나옵니다
- **화면 모드:** 설정에서 주간·야간 모드를 고르면 텍스트, PDF, zip 만화가 모두 그 모드로 열립니다
- **배경색:** 설정에서 흰색, 크림, 연회색, 연파랑 중 고르면 텍스트, PDF, zip 만화의 바탕에 적용됩니다 (야간 모드에서는 어두운 바탕)
- **정리:** 뷰어 메뉴의 사본 저장, 사진 회전, 공유, 야간 토글을 뺐습니다. 화면 모드는 설정에서만 바꿉니다
- **상단 툴바:** 텍스트, PDF, zip 만화가 같은 툴바와 같은 하단 위치 막대(숫자 포함)를 씁니다
- **페이지 넘기기:** 텍스트, PDF, ZIP 만화에서 좌우 가장자리 탭과 좌우 스와이프를 모두 사용할 수 있습니다. 가장자리 영역은 설정의 "페이지 넘김 터치 영역"에서 막대를 끌어 10~40%로 고르며, 고르는 동안 퍼센트가 바뀝니다
- **PDF 가로 넘기기:** 가로 페이지 모드에서 좌우 드래그로도 페이지를 넘깁니다. PDF 뷰어가 스와이프를 가로채지 않도록 직접 처리합니다
- **페이지 넘김 터치 영역:** 설정에서 화면 양쪽의 페이지 넘김 영역을 22%, 28%, 34%, 40% 중 고를 수 있으며 기본값은 28%입니다
- **메뉴 여는 영역:** 화면 가운데를 누를 때만 메뉴와 시스템 바가 켜지고 꺼집니다. 위·아래 가장자리는 반응하지 않습니다
- **공통 설정:** 화면 모드와 배경색은 설정 맨 위의 "공통" 항목에 모았습니다
- **하단 버튼:** 만화 하단의 버튼이 기기의 하단 바와 겹치지 않도록 여백을 줬습니다
- **텍스트 좌우 넘기기:** Markdown 등 기존 화면의 가로 모드는 스크롤 대신 한 화면씩 넘깁니다. 전용 텍스트 화면(.txt)에는 아직 없습니다
- **만화 가운데 탭:** 만화에서도 화면 가운데를 누를 때만 메뉴가 켜지고 꺼집니다

## 릴리즈 전 검증

APK를 릴리즈하기 전에는 반드시 에뮬레이터에서 디버그 빌드로 먼저 검증합니다.

1. `assembleDebug`로 빌드하고 에뮬레이터에 설치합니다.
2. 고친 동작을 직접 실행해 확인합니다. 스크린샷과 `logcat`, 진단 기록(`run-as <패키지> cat no_backup/diag.log`)으로 결과를 확인합니다.
3. 확인되지 않은 항목은 "확인하지 못함"으로 리드미 알려진 한계에 적습니다. 확인된 것만 "동작 확인"으로 적습니다.
4. 검증이 끝난 뒤에만 `assembleRelease`, 커밋, 태그, 릴리즈를 합니다.

에뮬레이터로 재현할 수 없는 항목(예: 파일 관리자 권한 흐름, 실기기 SD 카드)은 기기에서 확인해야 하므로 리드미에 명시합니다.

## 권한

물뷰는 저장소 권한을 요구하지 않습니다. 사용자에게 묻는 권한은 알림 하나뿐이고, 나머지는 설치할 때 자동으로 주어지는 일반 권한입니다.

- 인터넷: 업데이트 확인과 웹 뷰
- 설치 권한: 업데이트 APK 설치
- 알림 권한(POST_NOTIFICATIONS): 새 버전 알림용입니다. Android 13 이상에서 처음 한 번 묻습니다. 허용하지 않아도 앱은 그대로 동작합니다
- 네트워크 상태 읽기(ACCESS_NETWORK_STATE): 업데이트 확인 작업이 네트워크가 있는지만 봅니다. 데이터는 보내지 않습니다
- 백그라운드 작업(WorkManager가 쓰는 WAKE_LOCK, RECEIVE_BOOT_COMPLETED, FOREGROUND_SERVICE): 하루 한 번 업데이트를 확인하고, 재부팅 뒤에도 그 일정을 이어가기 위해 씁니다

파일은 다음 방식으로만 읽습니다.
- 파일 열기 선택기나 다른 앱이 준 파일 한 개의 권한
- 사용자가 선택창에서 허용한 폴더의 권한 (시스템이 폴더마다 묻고, 물뷰는 허용한 폴더만 읽습니다)

"모든 파일 접근" 권한은 쓰지 않습니다.

## 알려진 한계

- **텍스트 가로 보기와 줄바꿈 정리:** 전용 텍스트 화면에는 아직 없습니다. Markdown 등 다른 형식은 기존 화면을 씁니다
- **읽기 멈추기:** 이름이 바로 바뀌지 않는다는 보고가 있었습니다. 텍스트 화면은 메뉴를 다시 만들어 이름을 바꾸도록 코드를 확인했고, 에뮬레이터는 한국어 음성이 안 돼 읽는 도중의 이름은 볼 수 없었지만, 갤럭시 A23에서 잘 작동한다고 확인받았습니다(0.2.50)
- **0.2.53 확인하지 못함:** 문서에서 찾기의 개수·이전/다음 줄과 북마크의 항목별 삭제 버튼은 에뮬레이터 연결이 끊겨 기기에서 확인하지 못했습니다(컴파일만 확인). 업데이트 받기·설치 흐름과 `UpdateCheckerTest`(`ClassNotFoundException`으로 실행 안 됨)도 그대로 확인하지 못했습니다.
- **텍스트 찾기:** 영문 대소문자는 구분하지 않습니다(한글·기호는 그대로). 에뮬레이터에서 "hello"로 "Hello"를 찾는 것을 확인했고, 갤럭시 A23에서도 잘 작동한다고 확인받았습니다
- **zip 만화 쪽 수:** 쪽 수는 파일 수로 셉니다(이지뷰어처럼). 넓은 그림은 반쪽씩 넘기지만 한 쪽으로 세므로, 두 반쪽이 같은 쪽 번호이고 쪽 수는 열자마자 정해져 읽는 동안 바뀌지 않습니다. 예전에는 반쪽을 따로 세어서 쪽 수가 읽는 동안 늘었고(84 → 87 → 89, 0.2.49에서는 3~4번), 그 때문에 그림 크기를 미리 읽는 지연도 있었습니다. 에뮬레이터에서 시끌별 녀석들 1권(104장)을 열자마자 `1 / 104`가 나오고, 끝까지 넘겨도 104로 일정하며 마지막에 `104 / 104`가 됩니다. 이어보기·북마크·쪽 이동·위치 막대도 파일 번호 기준이고, 74쪽에서 강제 종료한 뒤 다시 열어도 `74 / 104`로 돌아옵니다. 갤럭시 A23에서도 잘 작동한다고 확인받았습니다. 한계: 이전 버전이 반쪽을 센 번호로 저장한 이어보기 위치는 어긋나서 처음부터 열릴 수 있습니다
- **텍스트 쪽 이동(키보드):** 갤럭시 A23에서 100을 넣으면 48쪽, 50을 넣으면 25쪽으로 가는 문제가 있었습니다(0.2.48). 쪽 번호를 입력하는 동안 키보드가 목록의 높이를 줄이고, 그 줄어든 높이로 줄 번호를 계산했기 때문으로 보입니다. 대화 상자를 열 때의 쪽 높이로 계산하도록 고쳤습니다. 에뮬레이터는 화상 키보드가 뜨지 않아 재현하지 못했지만, 갤럭시 A23에서 고쳐진 것을 확인받았습니다(0.2.49 이후)
- **폴더의 사진 넘기기(다운로드·미디어 제공자):** 파일 선택기의 "다운로드" 항목에서 고른 사진은 폴더 경로를 알 수 없어, 폴더를 허용해도 1장만 보이던 문제를 고쳤습니다. 이제 허용한 폴더에서 같은 이름과 크기의 파일을 찾아 엽니다. 에뮬레이터에서 208장짜리 폴더로 확인했고 갤럭시 A23에서도 잘 작동한다고 확인받았습니다. 이 찾기는 폴더 경로를 알 수 없는 파일에만 씁니다. 0.2.49에서는 경로를 아는 파일(파일 앱에서 연 사진)에도 적용되어, 다른 허용 폴더의 같은 이름·크기 파일로 잘못 열릴 수 있었고 이를 고쳤습니다
- **텍스트 설정 이름:** 설정의 "페이지 넘김 방식 (Markdown 등)"은 전용 텍스트 화면(.txt)에는 적용되지 않습니다. 이름을 바꿔 알렸을 뿐이고, .txt의 가로 페이지 넘김은 아직 없습니다
- **PDF 랙:** 실기기에서 PDF를 몇 쪽 넘기다 보면 화면이 오래 걸린다는 보고가 있습니다. 특히 가로 넘김 모드에서 다음 쪽이 5초쯤 걸리며, 앱을 다시 열어도 같다고 합니다. 에뮬레이터(WebView 156)에서 같은 모드로 40쪽을 넘겼을 때는 재현되지 않았고, 폰에서도 나중에 다시 해 보니 멀쩡했습니다(간헐적). 원인은 확인하지 못했습니다. 발열·절전 모드·메모리 부족이나 PDF 내용 때문일 수 있습니다. 다시 느려지면 진단 기록의 `pdf:` 줄(0.2.51부터 단계별)과 폰 상태를 함께 확인해야 합니다
- **업데이트 설치(0.2.52, 모듈 포팅):** 받기 퍼센트와 설치 단계를 업데이트 창에 보여 줍니다. 에뮬레이터에는 더 새 릴리스가 없어 받기와 설치 흐름을 실행하지 못했습니다(**확인하지 못함**). 단위 테스트 `UpdateCheckerTest`는 `testDebugUnitTest`에서 `ClassNotFoundException`으로 실행되지 않습니다(**확인하지 못함**). 릴리스 APK 이름은 모듈의 `ASSET`과 정확히 같은 `app-release.apk`여야 합니다.
- **JPG, PDF:** JPG는 같은 폴더의 다음 파일로 넘어가는 것을 확인했습니다. PDF 쪽 번호 입력도 갤럭시 A23에서 확인받았습니다
- **텍스트 끝에서 다음 파일, JPEG 끝 처리:** 실기기에서는 다음 파일 넘기기가 확인되었습니다. 찾기와 쪽 이동, 쪽 수 추정도 갤럭시 A23에서 잘 작동한다고 확인받았습니다
- **PDF 쪽 번호 입력:** 오른쪽 아래 쪽 표시를 눌러 쪽 번호를 입력합니다. 에뮬레이터(WebView 156)에서 열 수 있게 된 뒤로도 직접 보지는 못했지만, 갤럭시 A23에서 확인받았습니다
- **업데이트 실패:** 깃허브 파일 서버가 응답하지 않을 때(504) 앱 안에서 내려받지 못합니다. 이때 나오는 창의 "릴리즈 페이지 열기"로 브라우저에서 직접 받을 수 있습니다(빌드만 확인, 실제 실패 상황은 확인하지 못함)
- **텍스트 화면 확인:** 에뮬레이터에서 열기, 끝 이동, 찾기, 북마크, 이어보기, 글자 크기 반영, 가운데 탭 전체 화면을 확인했습니다. 갤럭시 A23에서도 잘 작동한다고 확인받았습니다
- 좌우 넘기기와 위치 막대, 북마크 위치는 기기에서 충분히 확인하지 않았습니다
- **다른 뷰어:** PDF, EPUB, 3D 모델, 표, 슬라이드 등의 로딩 문구와 오류 메시지를 한국어로 바꿨습니다
- **메뉴:** 홈 화면 메뉴의 Google Play 전환과 공유 항목을 뺐습니다

- Markdown 등 기존 화면에서는 텍스트 찾기가 지금까지 읽은 부분에서만 찾습니다. .txt 전용 화면은 파일 전체에서 찾습니다.
- 북마크 목록은 저장할 때 그 자리의 앞부분 글자로 이름을 붙이고, 이름이 없으면 번호로 보입니다.
- 이어보기는 뒤로 가기나 홈으로 나갈 때, 그리고 쪽을 넘기고 멈추면 저장됩니다. 앱을 강제로 꺼도 마지막으로 멈춘 위치까지는 남도록 고쳤습니다(에뮬레이터에서 `am force-stop` 뒤에도 같은 쪽으로 열리는 것을 확인했고, 갤럭시 A23에서도 확인받았습니다).
- 이전·다음 파일은 폴더에서 연 파일(또는 허용한 폴더 안의 파일)에만 나타납니다.
