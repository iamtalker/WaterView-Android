# 물뷰 Android

데스크톱 물뷰의 사용감을 안드로이드로 확장하는 올인원 파일 뷰어입니다.

## 기반

이 앱은 [Gander](https://github.com/mokshablr/gander)를 Android 파일 처리·문서·미디어 뷰어 기반으로 포크했습니다. Gander의 MIT 라이선스와 포함된 라이브러리별 고지를 유지하며, 물뷰의 이름·색상·아이콘·읽기 경험을 별도로 적용합니다.

## 지원 목표

- 이미지: JPG, PNG, GIF, WEBP, BMP, TIFF, SVG 등
- 압축 만화: ZIP, CBZ, CBR, RAR, 7Z 계열
- 문서·텍스트: PDF, Markdown, TXT, DOCX, XLSX, PPTX 등
- 동영상·음악: MP4, MKV, AVI, MOV, MP3 등

## 현재 구현

Gander의 Android 파일·문서 처리 기반 위에 물뷰의 한국어 UI와 읽기 경험을 적용했습니다. 일반 뷰어 기능에 더해 다음 항목을 구현했습니다.

- **만화:** 일본식 오른쪽에서 왼쪽 읽기, 한 화면 한 페이지 보기, 넓은 그림 반쪽 분할 보기
- **ZIP 만화:** 그림 위주 ZIP을 누르면 압축 목록 대신 만화 뷰어로 바로 열기
- **TXT·Markdown:** 스크롤 읽기와 좌우 탭 페이지 넘김 지원. TXT는 설정에서 세로 스크롤/가로 페이지 넘김을 고를 수 있고, 뷰어 메뉴에서 글자 크기를 조절합니다
- **PDF:** 세로 스크롤 또는 한 페이지씩 가로 넘김 선택, 넓은 페이지 반쪽 분할 옵션. 뷰어 메뉴에서 페이지 확대율을 조절합니다
- **PDF 조작:** 페이지 위치 막대, 가로 넘김 모드의 이전·다음 버튼, 읽기 도구 모음 표시·숨김
- **설정 반영:** PDF 보기 방식을 바꾸면 문서를 닫지 않고 현재 화면에 적용; 세로 스크롤에서는 하단 페이지 넘김 버튼 숨김
- **전자책·문서:** EPUB 장별 읽기와 DOCX·XLSX·PPTX 등 문서 뷰어
- **안정성:** 만화 페이지 전환 깜빡임 완화와 PDF 페이지 미리 준비
- **텍스트 뷰어:** 읽던 위치 이어보기, 북마크(추가·목록·이동·삭제), 강제 줄바꿈 정리(문단으로 잇기), 파일 안 찾기
- **최근 파일:** 파일 열기로 연 파일을 최근 목록에 표시하고 다시 열 수 있습니다. 목록의 줄을 길게 누르면 목록에서 뺄 수 있습니다
- **폴더 안 이동:** 폴더에서 연 파일은 메뉴에서 이전·다음 파일로 바로 넘어갈 수 있습니다. zip 만화는 zip 안의 마지막 쪽에서 다음을 누르면 같은 폴더의 다음 zip으로 넘어갑니다
- **읽어주기:** 텍스트 파일과 글자가 있는 PDF를 기기의 기본 음성으로 읽습니다. 메뉴의 "읽어주기"를 누르면 시작하고 "읽기 멈추기"로 멈춥니다. 음성 파일을 따로 넣지 않으며 인터넷을 쓰지 않습니다. PDF는 WebView 125 이상인 기기에서만 나타나고, 스캔한 PDF처럼 글자가 없으면 "읽을 글자가 없습니다"라고 알려 줍니다
- **만화 북마크:** 폴더나 zip의 만화에서 쪽을 북마크에 넣고 목록에서 그 쪽으로 이동할 수 있습니다. 북마크는 파일 이름과 쪽 번호만 저장합니다
- **이어보기:** zip 만화는 나갔다가 다시 열면 읽던 쪽에서 이어집니다. 텍스트 파일과 PDF도 읽던 위치에서 이어집니다
- **텍스트 화면:** 텍스트 파일은 전용 화면에서 엽니다. 파일을 복사해 줄 위치만 색인하고 보이는 줄만 읽어서, 수 MB 이상의 파일도 바로 열립니다. 위치 기억, 북마크, 문서에서 찾기, 읽어주기를 지원합니다. 페이지 넘김은 스냅 없이 부드럽게 스크롤합니다
- **텍스트 쪽 표시:** 하단 오른쪽 "현재 쪽 / 전체 쪽"을 누르면 쪽 번호를 입력해 그 쪽으로 갑니다. 쪽 수는 줄 높이의 평균으로 추정한 값이라 실제 쪽 경계와 조금 다를 수 있습니다
- **텍스트 탭 넘기기:** 화면 위쪽 3분의 1을 누르면 위로, 아래쪽 3분의 1을 누르면 아래로 한 화면씩 넘어갑니다. 가운데를 누르면 제목과 조작줄, 시스템 바가 사라지고 다시 누르면 돌아옵니다
- **텍스트 하단:** 진행 막대, ‹ › 버튼(한 화면씩), 설정 버튼이 있습니다. 설정 버튼은 읽기 설정 창을 엽니다. 글자 크기는 그 창의 TXT 보기에서 바꾸며, 텍스트 화면에 바로 반영됩니다
- **다음 파일 넘기기:** 폴더에서 연 PDF, 텍스트, 만화(jpg, zip)는 마지막 쪽에서 다음을 누르면 같은 폴더의 다음 파일을 이름순(1권, 2권, 10권)으로 엽니다. 다른 앱에서 열 때는 파일이 있는 폴더를 한 번 허용해야 합니다. 다음 파일이 없으면 그 자리에 머뭅니다
- **진단 기록:** 설정 맨 아래의 "진단 기록"에서 텍스트 쪽 나누기 과정을 보고, 복사하거나 지울 수 있습니다. 기록은 이 기기에만 있습니다
- **읽어주기 음성 언어:** 글에 한글이 있으면 한국어 음성으로 읽습니다. 한국어 음성이 기기에 없으면 기기의 텍스트 음성 변환 설정에서 설치해야 합니다
- **업데이트 알림:** 하루 한 번 새 버전을 확인하고, 새 버전이 있으면 알림을 띄웁니다. 앱을 열 때와 앱을 닫은 동안(WorkManager가 하루 한 번) 모두 확인합니다. 알림을 누르면 업데이트를 확인하는 창이 열립니다
- **밖에서 연 사진 넘기기:** 파일 관리자 등 다른 앱에서 연 사진은 그 사진의 폴더를 선택창에 미리 띄웁니다. "이 폴더 사용"과 허용을 한 번 누르면 같은 폴더의 사진을 옆으로 넘겨 볼 수 있습니다. 허용한 폴더는 기억하며, 목록에는 나열하지 않습니다
- **가로 위치 막대:** 텍스트 뷰어는 하단 막대로 파일 안의 위치(퍼센트)를 보고 끌어서 옮길 수 있습니다. PDF와 만화는 쪽 번호 막대로 같은 방식으로 이동합니다
- **가운데 탭 메뉴:** 텍스트, PDF, 만화 페이지의 가운데를 가볍게 누르면 툴바와 하단 막대가 나타나거나 사라집니다
- **전체 화면 유지:** 전체 화면에서 문서를 스크롤해 맨 위에 도달해도 툴바만 따로 나타나지 않습니다
- **PDF 북마크:** PDF 쪽을 북마크에 넣고 목록에서 바로 이동할 수 있습니다
- **만화 zip 제목:** 만화 상단에 파일 번호 대신 zip 파일 이름이 나옵니다
- **화면 모드:** 설정에서 주간·야간 모드를 고르면 텍스트, PDF, zip 만화가 모두 그 모드로 열립니다
- **배경색:** 설정에서 흰색, 크림, 연회색, 연파랑 중 고르면 텍스트, PDF, zip 만화의 바탕에 적용됩니다 (야간 모드에서는 어두운 바탕)
- **정리:** 뷰어 메뉴의 사본 저장, 사진 회전, 공유, 야간 토글을 뺐습니다. 화면 모드는 설정에서만 바꿉니다
- **상단 툴바:** 텍스트, PDF, zip 만화가 같은 툴바와 같은 하단 위치 막대(숫자 포함)를 씁니다
- **페이지 넘기기:** 텍스트, PDF, ZIP 만화에서 좌우 가장자리 탭과 좌우 스와이프를 모두 사용할 수 있습니다. 가장자리 영역은 설정의 "페이지 넘김 터치 영역"에서 막대를 끌어 10~40%로 고르며, 고르는 동안 퍼센트가 바뀝니다
- **PDF 가로 넘기기:** 가로 페이지 모드에서 좌우 드래그로도 페이지를 넘깁니다. PDF 뷰어가 스와이프를 가로채지 않도록 직접 처리합니다
- **페이지 넘김 터치 영역:** 설정에서 화면 양쪽의 페이지 넘김 영역을 22%, 28%, 34%, 40% 중 고를 수 있으며 기본값은 28%입니다
- **메뉴 여는 영역:** 화면 가운데를 누를 때만 메뉴와 시스템 바가 켜지고 꺼집니다. 위·아래 가장자리는 반응하지 않습니다
- **공통 설정:** 화면 모드와 배경색은 설정 맨 위의 "공통" 항목에 모았습니다
- **하단 버튼:** 만화 하단의 버튼이 기기의 하단 바와 겹치지 않도록 여백을 줬습니다
- **텍스트 좌우 넘기기:** TXT 가로 모드는 스크롤 대신 한 화면씩 넘기며, 큰 파일은 나머지를 읽으며 이어집니다
- **만화 가운데 탭:** 만화에서도 화면 가운데를 누를 때만 메뉴가 켜지고 꺼집니다

## 릴리즈 전 검증

APK를 릴리즈하기 전에는 반드시 에뮬레이터에서 디버그 빌드로 먼저 검증합니다.

1. `assembleDebug`로 빌드하고 에뮬레이터에 설치합니다.
2. 고친 동작을 직접 실행해 확인합니다. 스크린샷과 `logcat`, 진단 기록(`run-as <패키지> cat no_backup/diag.log`)으로 결과를 확인합니다.
3. 확인되지 않은 항목은 "확인하지 못함"으로 리드미 알려진 한계에 적습니다. 확인된 것만 "동작 확인"으로 적습니다.
4. 검증이 끝난 뒤에만 `assembleRelease`, 커밋, 태그, 릴리즈를 합니다.

에뮬레이터로 재현할 수 없는 항목(예: 파일 관리자 권한 흐름, 실기기 SD 카드)은 기기에서 확인해야 하므로 리드미에 명시합니다.

## 권한

물뷰는 저장소 권한을 요구하지 않습니다. 사용자에게 묻는 권한은 알림 하나뿐이고, 나머지는 설치할 때 자동으로 주어지는 일반 권한입니다.

- 인터넷: 업데이트 확인과 웹 뷰
- 설치 권한: 업데이트 APK 설치
- 알림 권한(POST_NOTIFICATIONS): 새 버전 알림용입니다. Android 13 이상에서 처음 한 번 묻습니다. 허용하지 않아도 앱은 그대로 동작합니다
- 네트워크 상태 읽기(ACCESS_NETWORK_STATE): 업데이트 확인 작업이 네트워크가 있는지만 봅니다. 데이터는 보내지 않습니다
- 백그라운드 작업(WorkManager가 쓰는 WAKE_LOCK, RECEIVE_BOOT_COMPLETED, FOREGROUND_SERVICE): 하루 한 번 업데이트를 확인하고, 재부팅 뒤에도 그 일정을 이어가기 위해 씁니다

파일은 다음 방식으로만 읽습니다.
- 파일 열기 선택기나 다른 앱이 준 파일 한 개의 권한
- 사용자가 선택창에서 허용한 폴더의 권한 (시스템이 폴더마다 묻고, 물뷰는 허용한 폴더만 읽습니다)

"모든 파일 접근" 권한은 쓰지 않습니다.

## 알려진 한계

- TXT 가로 페이지 넘김은 다양한 기기와 파일에서 추가 확인이 필요합니다
- **텍스트 가로 보기와 줄바꿈 정리:** 전용 텍스트 화면에는 아직 없습니다. Markdown 등 다른 형식은 기존 화면을 씁니다
- **읽기 멈추기:** 메뉴의 "읽기 멈추기"를 눌러도 이름이 바로 바뀌지 않는 문제가 있습니다. 확인 중입니다
- **텍스트 찾기:** 대소문자를 구분합니다. 에뮬레이터에서만 확인했습니다
- **zip 만화 쪽 수:** 끝으로 스크롤하면 총 쪽 수가 늘어나는 현상이 있습니다(예: 84 → 87 → 89). 원인을 확인하는 중입니다
- **JPG, PDF:** JPG는 같은 폴더의 다음 파일로 넘어가는 것을 확인했습니다. PDF 쪽 번호 입력은 기기에서 확인이 필요합니다
- **텍스트 끝에서 다음 파일, JPEG 끝 처리:** 실기기에서는 다음 파일 넘기기가 확인되었습니다. 찾기와 쪽 이동, 쪽 수 추정은 실기기 확인이 필요합니다
- **PDF 쪽 번호 입력:** 오른쪽 아래 쪽 표시를 눌러 쪽 번호를 입력하도록 연결했지만, 에뮬레이터는 PDF를 열 수 없어 확인하지 못했습니다
- **업데이트 실패:** 깃허브 파일 서버가 응답하지 않을 때(504) 앱 안에서 내려받지 못합니다. 잠시 뒤 다시 시도하거나 깃허브 릴리즈 페이지에서 직접 받아 주세요
- **텍스트 화면 확인:** 에뮬레이터에서 열기, 끝 이동, 찾기, 북마크, 이어보기, 글자 크기 반영, 가운데 탭 전체 화면을 확인했습니다. 실기기 확인이 필요합니다
- 좌우 넘기기와 위치 막대, 북마크 위치는 기기에서 충분히 확인하지 않았습니다
- **다른 뷰어:** PDF, EPUB, 3D 모델, 표, 슬라이드 등의 로딩 문구와 오류 메시지를 한국어로 바꿨습니다
- **메뉴:** 홈 화면 메뉴의 Google Play 전환과 공유 항목을 뺐습니다

- 텍스트 파일 찾기는 지금까지 읽은 부분에서만 찾습니다. 파일 끝 쪽에만 있는 말은 "더 보기"를 눌러 읽은 뒤에 찾을 수 있습니다.
- 북마크 목록은 저장할 때 그 자리의 앞부분 글자로 이름을 붙이고, 이름이 없으면 번호로 보입니다.
- 이어보기는 뒤로 가기나 홈으로 나갈 때 저장됩니다. 앱을 강제로 끄면 마지막 위치가 저장되지 않습니다.
- 이전·다음 파일은 폴더에서 연 파일(또는 허용한 폴더 안의 파일)에만 나타납니다.

- 텍스트 설정의 "페이지 넘김 방식"을 텍스트 화면에 맞게 정리하기 (지금은 텍스트 화면에 영향이 없습니다)
- 상단 툴바 색과 모양 다듬기
- 실제 만화 이미지가 든 zip으로 가운데 탭 메뉴 확인하기
- EPUB 호환성과 데스크톱 물뷰와의 읽기 경험 맞추기
- 대용량 ZIP의 메모리 사용량 및 페이지 전환 성능 개선
- 실제 기기와 다양한 파일로 뷰어 호환성 보강
- SD 카드에 있는 폴더의 사진 넘기기를 실기기에서 확인

기능은 실제 Android 에뮬레이터와 사용자가 제공한 파일로 확인합니다.
